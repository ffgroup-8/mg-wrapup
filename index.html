01 · The shift

From WordPress to built for what's next.

The old setup worked, but every site was its own maintenance job. Plugins piled up, content was duplicated, and each change meant touching many places. We replaced the foundation underneath every McNellie's website.

Where we started

WordPress Multisite + WooCommerce

  • Separate installs and plugin stacks to keep patched
  • Content copied by hand across group and restaurant sites
  • Inconsistent design from one concept to the next
  • Leftover boilerplate leaking into page titles and search results
  • Slow pages and limited control over SEO
→
Where you are now

Next.js + Sanity, headless

  • One content system for the group site and every restaurant
  • A shared component library, so new sites roll out fast
  • Fast, server-rendered pages with optimized images
  • Structured data on every location for Google and AI search
  • Gift cards and merch sold through the group shop

03 · The platform

One system behind every site.

Everything below is shared. Fix it once and it improves everywhere; add a restaurant and it inherits all of it on day one.

Sanity CMS

Edit everything in one place

A single content dataset for the group and every concept: menus, locations, hours, private rooms, gift cards and SEO fields.

Next.js

Fast by default

Server-rendered pages, optimized images and a mobile-first build across desktop, tablet and phone.

Design system

A Figma library to build from

Shared tokens, components and layouts, so each concept keeps its own look on a common foundation.

Commerce

Gift cards and merch

A headless group shop for gift cards and branded goods, in place of the old WooCommerce setup.

Consistency

The same structure on every site

Locations, menu, gallery, gift cards, rewards, catering and private dining, where they apply, all in the same place on every site.

Accessibility

Built for every guest

Semantic markup, keyboard navigation and contrast-aware design, plus an accessibility statement on every site.
